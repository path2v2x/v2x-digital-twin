# twin-server

SimForge OSS-native digital-twin server. It serves `/drive`, `/twin`, and `/camera-feeds` over WebSocket and `/health` plus `/streams/ch1..4.mjpg` over HTTP.

Dependencies come from the committed archives under `../../vendor/simforge-oss`, generated by `../../scripts/vendor-simforge-oss.sh v0.1.0-rc.60`. The map bundle defaults to `/home/path/simforge-oss/dev-assets/richmond-field-station` and can be changed with `TWIN_MAP_BUNDLE`.

```bash
pnpm install
pnpm --dir apps/twin-server start
```

`TWIN_WS_PORT` and `TWIN_HTTP_PORT` default to 8765 and 8090. `TWIN_CAMERA_URL_TEMPLATE` defaults to `rtsp://127.0.0.1:8554/{channel}`. Enable the co-perception poller with `TWIN_SYNC_LOCAL=1` and set `TWIN_DETECTIONS_URL` to its `/detections/latest` endpoint.

See `../../docs/twin-protocol-v2.md` for the wire contract.
